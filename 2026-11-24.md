## Agent Unit Explanations — a content-richness regression found, isolated, and fixed — 2 hours (10:30–12:30)

Source: `agent-unit-explanations/WORKLOG.MD`

**Problem**: the new explanations describe Suppiya only as "a wanderer," dropping a specific
definition the old version's Key Terms glossary had. Checked scope: a sweep of all 149 units'
Key Terms entry counts found a real net loss (786 → 764 entries, 41/149 units affected, two
units losing 4-5 entries each).

**Isolated the cause with a controlled experiment**: built versions of two of the worst-hit
units with the current storyteller rules but without the new cross-canon/preceding-units
context blocks. Both control versions matched or nearly matched the old entry counts —
confirming the new context blocks, not the rules or ordinary generation variance, were crowding
out the model's thoroughness elsewhere.

**Fix**: added rule 10 to `STORYTELLER_RULES` (the added context is supplementary only, never a
reason to cover less of the unit's own material), reinforced directly in the Key Terms
output-format instruction. Tested on 9 varied units first — 8/9 met or exceeded the old
baseline on the first attempt.

**Re-ran the full chapter with the fix**: 149/149 succeeded, $11.2615. Key Terms entries
chapter-wide: 786 → 1,168 (+382) — not just restored, genuinely richer; 132/149 units gained
entries, only 1 a single entry short. Regenerated the combined output file from the fixed
explanations.
