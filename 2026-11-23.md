## Agent Unit Explanations — pilot revised, a real accuracy bug found and partially fixed, full 149-unit run generated, a second instance of the same bug found and hand-patched — 9 hours (10:30–19:30)

Source: `agent-unit-explanations/WORKLOG.MD`

**Problem**: the pilot batch sampled units 1-5 sequentially, not representative of the whole
chapter. **Fix**: revised `build_pilot_prompts_cross_canon.py` to sample unit 1 plus 4 random
units (9, 35, 67, 87), and capped the preceding-units context block to the last 5 units instead
of every earlier one.

**Problem**: running the revised pilot found a real accuracy bug — the model said a figure
"abuses" the Buddha, but the root text only says he "spoke in dispraise of" him, an
overstatement. **Fix**: added a new storyteller rule (characterise the text with the word it
actually uses, not a stronger or weaker one), regenerated the same 5 units — confirmed the
overstatement was gone.

**Ran the real chapter-1 generation** after the fixed pilot passed, reusing the October run's
existing prompts rather than rebuilding them (avoids a needless second entity-extraction spend):
units 1-5 live as a final gate, units 6-149 via the Batch API. **Result: 149/149 succeeded,
$11.60 real cost.**

**Problem**: the storyteller-rule fix above only partially addressed the escalation-language
bug class. A later hand-comparison against the October version, swept across all 149 units for
other "loaded" words, found unit 16 independently escalating the source's "not proper" into "is
condemning" — the same class of overstatement, a different word pair the new rule didn't cover.
**Fix**: hand-patched unit 16 directly ("rules improper" in place of "is condemning") rather than
regenerating it, since this one instance didn't need a rule change to fix.

Confirmed the new storyteller rule doesn't over-suppress real abuse elsewhere in the corpus —
two other units still correctly use the word where the text supports it, so the rule
discriminates rather than blanket-suppresses.

**Built `combine_chapter1_cross_canon.py`** to produce the full 149-unit combined output file,
kept under its own name so it's never confused with the already-delivered October version.
