**Smoke tests (before trusting anything)**:
- **Teacher-forced scoring fails on this server**, on both completion endpoints: the correct

  alignment is impossible. Consistent with the original Shindan doc's section on impossible

- **Generation-time logprobs work cleanly**: one-token answers, no reasoning preamble, full

  3-sentence check ("Yes", 100%) — noted as a blind spot, not yet measured at scale.

**Built** a Yes/No and Percentage judge scorer for any OpenAI-compatible server (resumable, raw
top-20 persisted so new signals need no new requests — the language-drift lesson), an evaluation
runner, a paired-bootstrap signal analyzer, a sub-category analyzer, a category-stratified
sampler, and a category-stratified evaluation runner, plus 7 new tests.

**Results (full numbers and caveats in `LOCAL_JUDGE_CATEGORY_RESULTS.md`)**:
- **Pilot, pooled n=300** (identical rows to the OpenAI judges; the evaluation reproduces every
  earlier OpenAI number exactly): local DS4 Yes/No AUC 0.749 / 0.656 hard / 0.778 easy;
  Percentage expected value 0.769 / 0.642 / 0.799; `gpt-4.1` 0.736 / 0.658 / 0.807. **A local
  model matches the hosted judges.**
- **Percentage judge: the logprobs are what make it work.** The number the model states is near
  chance on the hard cut (0.551); the expected value over the top-20 numeric alternatives
  recovers ~0.09-0.10. On the pilot alone Yes/No and Percentage tied.
- Regenerated the gitignored dataset caches and the category join, after the user approved the
  downloads.
- **Real bug found and fixed**: an entire error sub-category was silently absent from the
  category join. Root cause: those rows carry inline markup tags in the raw source text, never
  matching the comparison copy. Fixed; match rate 94.8% -> 95.2%; earlier numbers moved by
  ≤0.002.
- **Category-stratified sample** (445 segments, 890 requests, 0 errors, ~6 min) pooled with the
  pilot. Judge is strongest on Accuracy sub-categories (~0.80-0.82 Mistranslation;
  ~0.74-0.78 Addition/Omission/Source fragment), middling on Fluency/Style (~0.65-0.71).
  **Terminology is weak: ~0.60 pooled (0.56 alone), not the ~0.70 the n=10 pilot suggested** —
  another case of a small-sample headline not surviving a stratified check.
- **Decision**: Yes/No P(Yes) is the primary local-judge signal. With the bigger sample,
  Percentage expected value is significantly worse on Fluency, Terminology, and
  Fluency/Inconsistency, so the pilot-only "they tie, keep both" call was reversed.
