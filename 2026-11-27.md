silently losing the override).

**Problem this surfaced**: the batch-generation script had the cross-canon rule set hardcoded
for both system-prompt caching and prompt-file validation — broken the instant a second rule
set existed. **Fix**: the script now detects which of the two known rule sets a given prompt

Verified the same way (unit 1 draft, same 5-unit sample) before scaling to the full batch
